# DungeonCrawler2d
A 2 - Dimensonal Dungeoncrawler with server

1. install node:mimetypes  and node in the directory with a CLI ./DungeoncrawlerMain
2. run " node ./DungeoncrawlerMain/dungeoncrawlerServer.js" in a CLI
3. request "localhost:3000" or "127.0.0.1:3000" in your browser
4. create account or use existing ( admin : 1234 | peter : 123 | paul : 123)
5. login as or create a user:
  5.a. as admin to create maps and enemies
  5.b. as normal user to create characters and play maps
6. have fun
7. logout
